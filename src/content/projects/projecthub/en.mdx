A project management platform: tasks, assignees, a kanban board and
role-based access control.

## What is inside

- **RBAC** — owner, admin and member, each with a different set of permissions.
- **Kanban** — tasks move between columns, and the state is persisted on the
  backend.
- **243 tests** — endpoints, access rules and state transitions are covered.

## Stack

FastAPI + PostgreSQL on the backend, React 19 and TypeScript on the frontend,
Docker to run the environment.

## Demo

Deployed on Render's free tier: a cold start takes about 30 seconds. After the
first request the application responds normally.
