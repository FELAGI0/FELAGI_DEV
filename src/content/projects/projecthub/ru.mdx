Платформа для управления проектами: задачи, исполнители, канбан-доска и
разграничение доступа по ролям.

## Что внутри

- **RBAC** — владелец, администратор и участник с разными наборами прав.
- **Канбан** — задачи перемещаются между колонками, состояние сохраняется
  на бэкенде.
- **243 теста** — покрыты эндпоинты, права доступа и переходы состояний.

## Стек

FastAPI + PostgreSQL на бэкенде, React 19 и TypeScript на фронтенде,
Docker для запуска окружения.

## Демо

Развёрнуто на Render free tier: холодный старт занимает около 30 секунд.
После первого запроса приложение работает в обычном режиме.
